# TTB Label Validator installation

1. Extract this ZIP file to a local folder.
2. Run `Ttb.LabelWeb.exe` from the extracted folder and keep its window open.
3. Open [http://127.0.0.1:5080](http://127.0.0.1:5080) in your browser.
4. Sample PDF files are located in `demo-data/pass-cases` and `demo-data/fail-cases`.
