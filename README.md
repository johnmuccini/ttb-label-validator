# TTB Label Validator installation

1. [Download TTB Label Validator 0.1.5 for Windows x64](https://github.com/johnmuccini/ttb-label-validator/releases/download/v0.1.5/TTB-Label-Validator-0.1.5-win-x64.zip).
2. Extract the ZIP file to a local folder.
3. Run `Ttb.LabelWeb.exe` from the extracted folder and keep its window open.
4. Open [http://127.0.0.1:5080](http://127.0.0.1:5080) in your browser.
5. Sample PDF files are located in `demo-data/pass-cases` and `demo-data/fail-cases`.
